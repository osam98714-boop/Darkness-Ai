## 📌 Overview

**Darkness** is a lightweight yet powerful WhatsApp bot built on the **MeowSab** framework. It delivers high performance with a clean architecture, making it easy to deploy, modify, and scale — perfect for both beginners and advanced developers.

## ✨ Features

| Category | Description |
| :--- | :--- |
| 🎭 **Reactions** | 60+ reaction GIFs (kiss, hug, slap, pat, etc.) |
| 🖼️ **Matching PP** | Random boy & girl matching profile pictures |
| 🤖 **AI Integration** | Smart AI chat, image generation, and intelligent responses |
| 🔘 **Buttons** | Full support for interactive Buttons V2 & V3 |
| 👋 **Welcome System** | Auto welcome & goodbye messages with group metadata |
| 🚫 **Moderation** | Ban / Unban users with a single command |
| 🏷️ **Nicknames** | Assign, view, and remove custom nicknames |
| ⚙️ **Group Settings** | Anti-link, Admin-only, Owner-only, and Welcome toggles |
| 🛡️ **Protection** | Auto-delete links & block banned users |
| 📥 **Downloaders** | Fetch media from YouTube, TikTok, Instagram & more |
| 🎨 **Logos & Design** | Built-in logo maker and image editing tools |
| 🎮 **Games & Fun** | Interactive games and entertainment commands |
| 🔍 **Search Engine** | Fast search for images, info, and content |
| ⚡ **Performance** | Blazing fast response with minimal resource usage |

## 🚀 Installation

### 🖥️ Termux (Android)

```bash
termux-setup-storage
pkg update -y && pkg upgrade -y
pkg install git nodejs ffmpeg -y
git clone [https://github.com/deveni0/Darkness-Ai.git](https://github.com/deveni0/Darkness-Ai.git)
cd Darkness-Ai
npm install --cpu=wasm32 sharp && npm install @img/sharp-wasm32
npm install
npm start

💻 VPS / Linux
sudo apt update && sudo apt install -y git nodejs npm ffmpeg
git clone [https://github.com/deveni0/Darkness-Ai.git](https://github.com/deveni0/Darkness-Ai.git)
cd Darkness-Ai
npm install
npm start
